# 🌌 **Piyush Goel's Portfolio** 🚀

✨ **Welcome to my personal portfolio!** This project showcases my skills, projects, experience, and education in a modern, responsive cyber-glassmorphism design. Built with React, Vite, TypeScript, Tailwind CSS, and Framer Motion. 🌟

---

## 🛠️ **Tech Stack**
| **Technology** | **Description** |
|-----------------|-----------------|
| **React 18**    | Modern UI library for fast, component-driven development. |
| **TypeScript**  | Type-safe frontend engineering. |
| **Tailwind CSS**| Utility-first styling with responsive design tokens. |
| **Framer Motion**| Fluid animations, staggered reveals, and scroll-linked progress. |
| **Vite**        | Ultra-fast module bundler & build tool. |
| **Lucide Icons**| Consistent vector icon sets. |

---

## 🚀 **Getting Started**

### **1. Install Dependencies**
```bash
npm install
```

### **2. Run Development Server**
```bash
npm run dev
```

### **3. Build for Production**
```bash
npm run build
```

### **3. Run the Development Server**
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

### **4. Build for Production**
```bash
npm run build
```

## 📂 **Project Structure**
```plaintext
├── public/               # Static assets
├── src/
│   ├── components/       # Reusable components (Navbar, Sidebar, etc.)
│   ├── pages/            # Page components (Home, About, Projects, etc.)
│   ├── styles/           # Global styles
│   ├── App.tsx           # Main app component
│   ├── index.tsx         # Entry point
├── tailwind.config.js    # Tailwind CSS configuration

├── package.json          # Project metadata and dependencies

```
